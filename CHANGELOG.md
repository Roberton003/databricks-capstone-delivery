## [4.0.0] - 2026-08-10

### Adicionado

- Repositório de entrega profissional do Databricks AI Bootcamp Capstone
- README completo com histórico e justificativa do projeto
- Documentação técnica detalhada da arquitetura
- Lista de ferramentas e tecnologias utilizadas
- Guia de configuração e execução
- Status de entrega com componentes implementados e pendentes
- Guia para recrutadores e tech leads
- Licença e direitos autorais claros

### Mudanças

- Proposta formalizada: **Stock-Market Research Assistant**
- Remoção de trading como requisito obrigatório
- Foco em pesquisa, notas e relatórios como ações de escrita do agente
- Atualização de arquitetura para refletir o propósito final
- Atualização de status: "Deploy Databricks" agora é o último passo

### Notas

- Este é um repositório de entrega para portfolio/profissional
- O código original foi mantido intacto para referência
- Este projeto não deve ser usado para decisões financeiras reais
